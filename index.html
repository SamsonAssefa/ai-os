Connect any agent

AI OS uses a small JSON API, so agents built with any language or framework can connect.

POST /api/v1/agents POST /api/v1/objectives GET /api/v1/objectives POST /api/v1/tasks PATCH /api/v1/tasks/{id}

Build a capability

Package an adapter that declares its API version, permissions, inputs, and outputs. Plugins return proposals; the host checks them against objective limits.

Read extension contract →
{ "name": "my-agent-adapter", "version": "0.1.0", "api_version": "v1", "requested_permissions": ["read:objectives"] }

Safety at a glance

Budget ceilings are checked by the API.
Objectives remain proposals pending human review.
Task state and agent reports are recorded in an audit feed.
This is an in-memory local MVP. Use behind a trusted network; production identity, storage, rate limits, and isolated plugin execution remain future work.
